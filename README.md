# [manacode] LazyBuffBar 0.2.0-beta.1 — бета

Панель бафов для WoW 3.3.5a: что держать твоему классу и спеку. Самобафы, рейдовые бафы со счётом по рейду,
фласка, еда и препоты, проки, кулдауны, тринкеты с внутренним откатом и доты на цели — для всех 35 спеков.
Отдельная группа «ждём» показывает, какие бафы тебе должны дать другие классы в этом рейде.

**Установка**
1. Распакуйте архив в `Interface\AddOns` — должна получиться папка `ManaCode_LazyBuffBar`.
2. Полностью перезапустите клиент: `/reload` новую папку не увидит.

Переходите с папки `LazyBuffBar`: выйдите из игры и скопируйте `WTF\Account\<аккаунт>\SavedVariables\LazyBuffBar.lua`
в `ManaCode_LazyBuffBar.lua` рядом — иначе панель начнёт с настроек по умолчанию.

**Что нового в этой бете**
- Панели на сетке: свои полосы любого размера, перетаскивание иконок между клетками и полосами, новая полоса броском в пустое место.
- Заводские пресеты для каждого спека, свои пресеты, привязка к ветке талантов, библиотека панелей «Мои» и «Заготовки».
- Режим настройки: полоска сверху экрана, плашка панели (размер, условия показа, вид) и плашка кнопки (показ, что и на ком отслеживать).
- Окно «+» — библиотека: «Мой персонаж» по группам, фильтр «Моё · Всё», превью «как на панели», поиск по всему и по #id.
- Виджеты: общие (угроза, тринкеты, сытость, часы, задержка, прочность, меткость, дебафы на цели) и классовые — по 2–3 на класс и по виджету почти на каждый спек.
- Откат, который вешает на тебя баф (Гнев карателя, Глухая оборона…), показывает таймер бафа, пока он висит.
- Способности боссов ЦЛК и РС — видны только в своём бою.
- Стили иконок и тем, условия показа по ХП и ресурсу, раздача PallyPower у кнопок благословений.

**Настройка**
- Кнопка у миникарты: левый клик — режим настройки (двигать и править панели), правый — окно настроек.
- В режиме настройки: «+» в пустой клетке — добавить, наведение на иконку — её плашка, клик по отступу панели — плашка панели.
- Профили на весь аккаунт: у основного и второго спека свой, при смене спека панель переходит на него сама.

Это бета: что-то может выглядеть сыро. Об ошибках пиши со скриншотом.

Слэш-команд нет: всё — в интерфейсе.
