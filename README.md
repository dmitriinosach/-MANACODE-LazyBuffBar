# [manacode] LazyBuffBar 0.1.0-beta.1 — бета

Панель бафов для WoW 3.3.5a: что держать твоему классу и спеку. Самобафы, рейдовые бафы со счётом по рейду,
фласка, еда и препоты, проки, кулдауны, тринкеты с внутренним откатом и доты на цели — для всех 34 спеков.
Отдельная группа «ждём» показывает, какие бафы тебе должны дать другие классы в этом рейде.

**Установка**
1. Распакуйте архив в `Interface\AddOns` — должна получиться папка `ManaCode_LazyBuffBar`.
2. Полностью перезапустите клиент: `/reload` новую папку не увидит.

Переходите с папки `LazyBuffBar`: выйдите из игры и скопируйте `WTF\Account\<аккаунт>\SavedVariables\LazyBuffBar.lua`
в `ManaCode_LazyBuffBar.lua` рядом — иначе панель начнёт с настроек по умолчанию.

**Настройка**
- `/lbb settings` или шестерёнка у полосы — окно настроек; замок — зафиксировать панель.
- Правый клик по разблокированной полосе — её вид: прозрачность, затухание без мыши в бою и вне боя, фон, поля, расстояние.
- Полосы тянутся с направляющими по краям и центрам соседей и экрана; Alt — свободно.
- Края иконок, кант фона, яркость без бафа, цифры свои или OmniCC, подкраска кулдаунов «далеко» и «нет маны».
- Настройки общие на аккаунт или только для этого персонажа (`/lbb char`).

Команды: `/lbb` — показать или скрыть, `/lbb lock`, `/lbb reset`, `/lbb scale N`, `/lbb settings`, `/lbb char`,
`/lbb why` — почему строка «ждём» показана или нет, `/lbb fake` — подставной состав рейда для проверки.
